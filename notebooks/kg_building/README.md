Я на выходных запустил построение графа знаний на HotpotQA-датасете (distractor/validation, v1-версия промптов). Прогресс: ~ 5.5k / 13k. Ещё потребуется построить граф на v2-версии промптов + аналогичную операцию выполнить для TriviaQA-датасета.

Можно тебя попросить заняться построением графов для других датасетов? Потребуется привести датасеты в нужный формат + написать небольшие функции по чтению контекстов. Требуемые алгоритмы действий я сформулировал ниже. Актуальный код для этой задачи лежит в ветке task#76 (https://github.com/zer0o0ne/Personal-AI/tree/task%2376).

Алгоритм подготовки датасета для построения графа знаний на его основе:
0. Создать директорию с названием данного датасета в "data/qa_datasets"-каталоге.
1. В созданном каталоге (с шага 0) должно быть создано/храниться два скрипты: load_data.py и prep_contexts_df.py.
2. C помощью load_data.py выполнить скачивание/урезание датасета. Полученная версия датасета сохраняется в отдельный подкаталог.
3. С помощью prep_context_df.py создать csv-файл, где должны хранятся уникальные контексты из полученной версии датасета (с шага 2); csv-файл должен состоять из трёх колонок: "context" - текст на естественном языке, "title" - заголовок контекста (если есть, инчае None) и qa_idx - индексы question/answer-пар в полученной версии датасета, к которым относится данный контекст.
4. В notebooks/kg_building/create/create_kg.py добавить функцию для загрузки списка контекстов из соответствующего relevant_contexts.csv-файла. Реализованную функцию добавить в CUSTOM_LOAD_FUNCS-словарь (в том же create_kg-скрипте).

Алгоритм запуска построения графа знаний (необходимые скрипты находятся в "notebooks/kg_building/create"-каталоге):
0. Указать значения гиперпараметров построения графа в params.yaml.
1. Запустить init_file_structure.py с указанием пути до полученного params.yaml (с шага 0). В результате будет инициализирована директория для хранения графа знаний: данная директория будет находиться в "data/knowledge_graphs/{название_датасета}/"-каталоге,
2. Запустить get_dc_envfile.py с указанием пути до полученного params.yaml (с шага 0). В результате будет получен .env-файл для конфигурации/запуска необходимых контейнеров через docker-compose.
3. Поднять workspace-контейнер через docker-compose с использованием полученного .env-файла (с шага 2). Требуемый docker-compose-файл находится в "notebooks/kg_building"-каталоге.
4. Зайти в созданный workspace-контейнер.
5. Запустить create_kg.py с указанием пути до полученного params.yaml (с шага 0).
