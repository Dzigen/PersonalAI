Структура файловой системы:
- debug/ - ноутбуки/скрипты с отладкой кода из каталога "src".
- experiments/ - каталог с реализациями проводимых экспериментов: дообучение/обучение моделей, подбор гиперпараметров модели и т.п. Каждый эксперимент в отдельной папке. Обязательно логирование экспериментальных процессов в отдельные каталоги "logs" (для каждого каталога с экспериментом свой каталог с логами): пул гиперпарметров + полученные метрики качества результатов эксперимента.
    notebooks/ - переиспользуемые ноутбуки: связанные с предобработкой датасетов, формированием баз данных и т.п.
- src/ - исходный код проекта
- tests/ - модульные/интеграционные тесты для кода из каталога "src".
- models/ - каталог с нейросетевыми моделями (в репозиторий не пушим)
- data/ - каталог с датасетами/базми данных (в репозиторий не пушим)
- docs/ - документация проекта.
